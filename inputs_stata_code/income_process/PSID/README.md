# PSID input for the income-process pipeline

`psid.dta` is the raw PSID public-use extract used by `inputs_stata_code/income_process`.

For journal replication, the preferred distribution route is the official PSID Repository
for publication extracts, because PSID Conditions of Use restrict direct transfer of data
downloaded from the PSID website to third parties. If the publication extract is not supplied,
replicators should obtain the data from https://psidonline.isr.umich.edu/ and place the file at:

```
inputs_stata_code/income_process/PSID/psid.dta
```

The replication package also includes processed PSID-derived files:

```
data/PSID/psid_ready.dta
data/PSID/ageeffects_mostdrop_hhslabinc_avghourlyhh.dta
data/PSID/ageeffects_busno_drop_hhslabinc_avghourlyhh.dta
```

The `psid_ready.dta` file is generated by the mostdrop PSID income-process sample and is used by
`outputs_stata_code/MvD_2_Gini_income.do` for Appendix Figure D.4. The `ageeffects_*.dta` files
are generated by the Deaton-Paxson decomposition and are used by
`outputs_stata_code/income_process/plot_omega.do` for Appendix Figure B.4. Re-running Step 2B
refreshes these files when the raw PSID extract is available.

The optional `psid_read.R` script records the extraction route used by the authors: it uses
`psidR` to build the raw PSID panel and writes `psid.dta`. The Stata pipeline then creates both
income-process variants, the processed `psid_ready.dta` panel, Deaton age-effect estimates,
omega inputs, and covariance files for MATLAB.

# PSID input for the income-process pipeline

`psid.dta` is the raw PSID public-use extract used by `inputs_stata_code/income_process`.

For journal replication, the preferred distribution route is the official PSID Repository
for publication extracts, because PSID Conditions of Use restrict direct transfer of data
downloaded from the PSID website to third parties. If the publication extract is not supplied,
replicators should obtain the data from https://psidonline.isr.umich.edu/ and place the file at:

```
inputs_stata_code/income_process/PSID/psid.dta
```

The replication package also includes processed PSID-derived files:

```
data/PSID/psid_ready.dta
data/PSID/ageeffects_mostdrop_hhslabinc_avghourlyhh.dta
data/PSID/ageeffects_busno_drop_hhslabinc_avghourlyhh.dta
```

The `psid_ready.dta` file is generated by the mostdrop PSID income-process sample and is used by
`outputs_stata_code/MvD_2_Gini_income.do` for Appendix Figure D.4. The `ageeffects_*.dta` files
are generated by the Deaton-Paxson decomposition and are used by
`outputs_stata_code/income_process/M05plot_omega.do` for Appendix Figure B.4. Re-running Step 2B
refreshes these files when the raw PSID extract is available.

The optional `psid_read.R` script records the extraction route used by the authors: it uses
`psidR` to build the raw PSID panel and writes `psid.dta`. The Stata pipeline then creates both
income-process variants, the processed `psid_ready.dta` panel, Deaton age-effect estimates,
omega inputs, and covariance files for MATLAB.

## Extraction and required contents

The authors' extraction uses the PSID Main Study family and individual files, the SRC sample,
heads only, and waves 1970-2019. `psid_read.R` builds the panel from the `psidR` variable lists
`famvars_big.txt` and `indvars.txt`. Those lists map PSID wave-specific variable names into the
harmonized names consumed by the Stata scripts, and **both list files are included in this folder**
(1,055 family-variable and 121 individual-variable wave mappings). The script looks for them next
to itself first, so no configuration is needed; it falls back to the installed `psidR` package
directory, and stops with an explicit message if neither location has them. Environment-variable
overrides remain available:

```bat
set PSID_FAMVARS=C:\path\to\famvars_big.txt
set PSID_INDVARS=C:\path\to\indvars.txt
set PSID_DATADIR=C:\path\to\downloaded\psid\files
Rscript inputs_stata_code\income_process\PSID\psid_read.R
```

`PSID_DATADIR` must point to a folder with the PSID family/individual files downloaded from the
PSID Data Center (psidR stores them as `FAM<year>ER.rda` and `IND2019ER.rda`).

The old exploratory `getNamesPSID` example that referenced `Downloads/psid.xlsx` is not part of
the replication pipeline and has been removed from `psid_read.R`.

The Stata pipeline expects the resulting `psid.dta` to include, at minimum, these harmonized fields:

- identifiers and timing: `pid`, `year`, family/person identifiers carried by `psidR`
- demographics and weights: `age`, `educ`, `weight`
- hours: `hours`, `hours_wife`
- labor-income components: `wife_labinc_exc`, `wife_labinc_bus`, `wife_labinc_inc`, `wife_assinc_bus`, `wife_farm`, `hdslabinc_exc`, `hdslabinc_bus`, `hdslabinc_inc`, `hdsassinc_bus`, `total_assinc_bus`

`I01_01_prepare_common_sample.do` is the first scripted transformation from raw PSID to processed
data. It renames `hours` to `hdshours`, constructs household labor income and business-income
components, deflates income to the script's January-2000 price base, restricts to ages 20-65,
recodes education, constructs birth cohorts, and applies panel-continuity and outlier filters.
`I01_02_make_variant_samples.do` then creates the `mostdrop_hhslabinc` and `busno_drop_hhslabinc`
variants. The packaged `data/PSID/psid_ready.dta` is generated from `mostdrop_hhslabinc` after
dropping households whose five-year business-income share exceeds 25 percent and whose labor income
is above the year-specific first quartile.

The PSID Data Center documentation does not list a dataset DOI for the collection itself. Cite PSID
as the provider, specify the waves used, and cite the PSID Data Center and documentation pages:
https://psidonline.isr.umich.edu/ and https://psidonline.isr.umich.edu/Guide/documents.aspx.
The authors' exact extract has its own DOI via the PSID Public Data Extract Repository (see below).

## Complete variable inventory of the authors' extract

The authors' `psid.dta` contains 166,576 person-year observations (waves 1970-2019) and exactly
these 74 harmonized variables (produced by `psid_read.R` via `psidR`):

- identifiers and timing: `ID1968`, `pernum`, `sequence`, `pid`, `interview`, `year`, `fchg`
- demographics, education, and weights: `age`, `sex`, `state`, `educ`, `relation_head`,
  `empstat`, `weight`
- hours and hourly income: `hours`, `hours_wife`, `avghourly`
- household and head/spouse income: `faminc`, `hdslabinc_inc`, `hdslabinc_exc`, `hdslabinc_bus`,
  `hdsassinc_bus`, `wife_labinc_inc`, `wife_labinc_exc`, `wife_labinc_bus`, `wife_assinc_bus`,
  `wife_farm`, `total_assinc_bus`
- business ownership and involvement (up to five businesses, suffixes `_1`-`_5`):
  `be_*`, `hd_own_*`, `wife_own_*`, `hd_working_in_*`, `w_working_in_*`, `net_inc_*`,
  `profits_*`, `loss_*`, `unincorporated_*`, plus `bus_at_all`

The exact extract (identical file) is archived in the PSID Public Data Extract Repository,
PSID's sanctioned channel for sharing publication extracts: ICPSR ID 307887, published
July 9, 2026, https://doi.org/10.3886/E307887V1. Replicators can obtain the byte-identical
`psid.dta` there instead of rebuilding it from the PSID Data Center.
